### Breaking

- `PeerTxRegistry` is a record keyed by `PeerRegistration`, the peer's
  address and a registration number, so a release removes its own entry
  when an address is registered twice; `retirePeerCounters` takes the
  registration.

### Non-Breaking

- The V2 counters snapshot reads in small transactions: the retired
  accumulator with the list of live cells, then each cell on its own. One
  transaction over every peer's cell was restarted by each peer's write.
  Retiring a peer still moves its counts in the transaction that
  unregisters it, so every peer is counted exactly once.
- Exported `snapshotCountersWith`, which takes the transaction runner, and
  `retirePeerCounters` from `Ouroboros.Network.TxSubmission.Inbound.V2.Registry`.
