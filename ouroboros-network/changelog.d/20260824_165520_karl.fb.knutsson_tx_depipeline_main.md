### Breaking

- Remove the disablePipelinedTxIdRequests field from TxDecisionPolicy

### Non-Breaking

- V2 tx-submission pipelines a txid request only when it both acks and
  requests, so a peer whose txids are all unacked and unresolved is not
  polled with `ack=0, req=N` messages.  Stricter than V1, which pipelines
  such a poll after a body request while the window has room.
