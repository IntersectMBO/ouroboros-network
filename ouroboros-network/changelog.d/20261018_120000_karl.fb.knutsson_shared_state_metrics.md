### Breaking

- `TraceSharedTxState` carries the counts (`SharedTxStateCounts`) beside
  the state, folded once by the counters thread for every renderer, and
  the counts' names are listed by hand rather than derived.

### Non-Breaking

- The V2 shared tx state's counts are metrics as well as a trace:
  `TraceSharedTxState` now carries `txSubmission.sharedState.revision`,
  `txSubmission.sharedState.generation` and one gauge per count of
  `sharedTxStateCounts` (`activeTxCount`, `retainedTxCount`,
  `internedTxCount`, `leasedTxCount`, `claimableTxCount`,
  `totalAttemptCount`, `submittingTxCount`, `advertiserCount`), emitted
  when the state changed, at the counters thread's cadence and whatever
  the trace's severity, so the rate of writes to the shared state and its
  sizes can be watched without the Debug trace.
